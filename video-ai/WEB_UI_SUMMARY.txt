🚀 快速启动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 安装依赖:
   pip install streamlit moviepy openai-whisper yt-dlp

2. 安装 FFmpeg:
   sudo apt-get install ffmpeg  # Ubuntu/Debian
   brew install ffmpeg          # macOS

3. 启动应用:
   ./run_web_ui.sh
   # 或
   streamlit run examples/web_ui.py

4. 打开浏览器:
   http://localhost:8501
