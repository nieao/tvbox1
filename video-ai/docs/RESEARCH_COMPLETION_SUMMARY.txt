================================================================================
核心研究发现
================================================================================

1. 三层处理架构
   ┌─────────────────────┐
   │ 转录层: WhisperX    │ (Replicate API)
   │ LLM 层: Claude      │ (Anthropic)
   │ 片段层: 智能识别    │ (两阶段 AI)
   └─────────────────────┘

2. Prompt 工程的三层结构
   第 1 层: 总结生成 (输入: 完整转录, 输出: 结构化总结)
   第 2 层: 主题提取 (输入: 总结, 输出: JSON 主题列表)
   第 3 层: 片段识别 (输入: 转录+主题, 输出: 时间戳列表)

3. 智能片段创建的关键特性
   - 两阶段 AI 方法确保准确性
   - 0.5 秒缓冲防止音频断裂
   - 2-5 分钟时长约束保证可看性
   - JSON 容错解析提高鲁棒性

4. 值得借鉴的设计模式
   - 模块化代码组织 (职责分离清晰)
   - 异步处理架构 (避免阻塞)
   - YAML 外部配置 (灵活部署)
   - 健壮的容错设计 (JSON 解析容错)
