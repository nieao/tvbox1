================================================================================
API INTEGRATION
================================================================================

Authentication:
POST https://api.video-ai.com/api/v1/auth/verify
  Header: Authorization: Bearer {token}

Video Processing:
POST https://api.video-ai.com/api/v1/videos/process
  Body: { video_url, user_interests, output_length }

Job Status:
GET https://api.video-ai.com/api/v1/jobs/{job_id}
  Header: Authorization: Bearer {token}

Polling:
- Interval: 2 seconds
- Max attempts: 180 (6 hours total)
- Timeout: 30 seconds per request

================================================================================
STORAGE AND CONFIGURATION
================================================================================

Settings Stored in chrome.storage.sync:
- apiToken: API authentication token
- userId: User ID from Video-AI
- interests: User interest tags (comma-separated)
- outputLength: Default output length (short/medium/long)
- language: UI language (zh-CN/zh-TW/en)
- autoDownload: Auto-download completed videos
- enableNotifications: Show desktop notifications
- saveHistory: Save processing history
- cacheDays: Cache retention days (1-90)

Local Cache:
- chrome.storage.local for temporary data
- Auto-expiration based on cacheDays setting
